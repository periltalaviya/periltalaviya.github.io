03 experience

Where I've worked

Founding Engineer

Zephyr Pvt Ltd

Sep 2023 — Present
Bengaluru
  • Joined with no code and no infrastructure. Set up the Azure, database, repositories and both codebases, designed the data model and the APIs, and took the product live. It now runs across three environments.
  • Wrote the video generation pipeline on ffmpeg. It mixes narration, sound effects and a background music with separate volume control per track, and handles animations and transitions. Also integrated OpenAI, Google Veo and Magnific for image and video generation.
  • Built authentication end to end: email and password sign in for the admin portal, mobile number and OTP for end users, and the password reset flow. Also built role based access control, checked on every endpoint and reflected in the UI.
  • Added Redis rate limiting on login, OTP and password reset with separate limits per account and per IP.
  • Integrated Gupshup for WhatsApp and OTP, including the delivery webhooks, so the admin screens show whether a message was sent, delivered, read or failed.
  • Optimised MongoDB connection management by eliminating duplicate pools, reducing idle connections by 50% and improving API resilience under load.
  • Built a reusable email module on Azure Communication Services that keeps templates in the database, so transactional wording changes without a deploy.
  • Built the speech layer: text to speech, speech to text and translation. Started on Microsoft AI Foundry and later moved it to ElevenLabs for better voice quality and word level timings.
  • Set up production routing with Azure Application Gateway and Nginx, and put Front Door in front of static assets to cut latency and egress cost. Sized the VMs from load tests rather than guesswork, added machines as traffic grew, and later moved the whole infrastructure to OpenTofu.
  • Moved deployments off the VMs into Docker images in Azure Container Registry, driven by GitHub Actions. The deploy logic had been duplicated on every machine and in every repo, so I pulled it into one place as reusable workflows. Added version endpoints and a daily job that checks the running build is the one that was actually deployed.
  • Built a fair amount of the product itself: a Chrome extension that captures live web pages, a Konva based editor for editing them, a Python service that parses PowerPoint into our format, and the PDF, SCORM and video export paths.
  • Handled VAPT findings, moved secrets out of GitHub Actions into Azure Key Vault, locked cloud access behind a VPN, and ran DR drills on the database and the machines.
